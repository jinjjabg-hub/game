# 팀한판

폰으로 QR을 찍고 들어와 팀 대항 게임을 하는 행사 진행 프로그램입니다.
BNI 챕터 모임·송년회처럼 여러 명이 모인 자리에서 **MC 없이도 분위기를 띄우고, 점수 집계를 자동으로** 하기 위해 만들었습니다.

## 들어 있는 것

| 구분 | 내용 |
|---|---|
| 한 화면 게임 (서버 불필요) | BNI 퀴즈 · 딱 10초 · 점수판 · 최종 발표 — 폰 없이 큰 화면 하나로 진행 |
| 경품 추첨 (서버 불필요) | 이름 룰렛 · 달리기 경주 · 돌림판 · 카드 뒤집기 · 사다리 · 슬롯 · 풍선 서바이벌 · 스포트라이트 · 공 추첨기 |
| 폰 접속 게임 (서버 필요) | 연타 대결 · 흔들어라 · 딱 10초 · BNI 퀴즈 · 두더지 잡기 · 숫자 순서 · 다른 색 찾기 · 암산왕 · 색깔 함정 — 참가자가 QR로 입장 |
| 자동 처리 | 실시간 점수 막대, 게임별 순위 점수, 종합 순위, 최종 발표(꼴찌부터 공개 + 폭죽) |

## 어디서 열리나

| 주소 | 되는 것 |
|---|---|
| GitHub Pages (`github.io`) | 한 화면 게임, 경품 추첨 |
| 서버 배포 주소 (Render 등) | 위 전부 + 폰 접속 게임 |

폰 접속 게임은 폰과 큰 화면을 실시간으로 이어 주는 서버가 있어야 해서, 파일만 보여 주는 GitHub Pages에서는 잠겨 있습니다.

## 실행

```bash
npm install
```

```bash
npm start
```

브라우저에서 `http://localhost:3000` 을 엽니다.

> 참가자 폰이 접속하려면 인터넷에 올려야 합니다. 이 저장소를 [Render](https://render.com)에 연결하면 `render.yaml` 설정대로 바로 배포됩니다.
> 폰 흔들기 센서는 `https` 주소에서만 동작합니다(Render는 기본 https).

## 진행 방법 (3단계)

1. **노트북**에서 접속 → `새 행사 시작` → 큰 화면에 QR이 뜹니다.
2. **참가자**는 폰으로 QR을 찍고 팀을 고릅니다. (앱 설치·가입 없음)
3. 게임을 고르고 **스페이스바**. 끝나면 `최종 발표`.

| 키 | 동작 |
|---|---|
| `←` `→` 또는 숫자 | 게임 고르기 |
| `Space` | 시작 / 다음 / 한 팀씩 공개 |

- `팀 설정`: 팀 이름·팀 수 변경 (최대 20팀)
- `퀴즈 문제 편집`: 한 줄에 `질문 | 보기1 | 보기2 | 보기3 | 보기4 | 정답번호`
- 결과 화면의 `이 결과 취소`, 순위판의 `±10`으로 점수 보정
- 노트북이 꺼져도 같은 브라우저로 다시 열면 `이어서 진행`

## 점수 규칙

- 팀 점수 = 그 팀 폰들의 **평균** (폰 대수가 달라도 공정)
- 게임마다 1위가 `팀 수 × 10`점, 한 순위 내려갈 때마다 10점씩 줄어듭니다.
- 퀴즈: 정답 100점 + 빨리 맞힐수록 최대 50점. 보기 순서는 매번 섞입니다.

## 구조

| 파일 | 역할 |
|---|---|
| `server.js` | 방 관리, 점수 집계, QR 생성 (Express + WebSocket) |
| `public/host.*` | 큰 화면(진행자) |
| `public/play.*` | 참가자 폰 |
| `public/solo.html` | 한 화면 게임 (서버 없이 브라우저에서만 동작) |
| `public/draw.html` | 경품 추첨 (서버 없이 브라우저에서만 동작) |
